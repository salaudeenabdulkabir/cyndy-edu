## Verdict

**Private test preview: ready for a controlled deployment and role-by-role acceptance testing. Public launch: DO NOT SHIP yet.** The redesign branch is not the build currently running on Render staging. Do not present the preview fee or account as real payment instructions.

## Verified on `codex/portal-opportunity-redesign`

- `npm run lint`, `npm run typecheck`, `npm run build`, and all 54 regression tests passed.
- `npm run check:secrets` passed. `npm audit --omit=dev` reported zero vulnerabilities after updating the transitive `brace-expansion` lockfile entries. A full audit still reports development-tool advisories in Tailwind's watcher chain and Drizzle Kit's old esbuild chain; `npm audit fix --force` would introduce breaking major changes, so those were not applied under the deadline.
- Isolated local preview used the redesign Neon branch, the private test R2 bucket, disabled email, and unapproved legal-policy setting. Admin access reached the PIN screen and the dashboard after the site owner entered their PIN. Read-only checks opened Opportunities & Payments, Workers, Countries & Programs, and Document checklist. Mutating admin actions still need a controlled dummy-data walkthrough.
- Public homepage and support page had no violations in automated axe WCAG 2.2 AA checks. At 375 px, the homepage and support page had no page-wide horizontal overflow. The low-contrast gold text and links found in the applicant area were darkened on light surfaces; the applicant area needs a repeat axe check after sign-in.
- Visual regression is **INCONCLUSIVE**: no committed screenshot baseline exists. Core Web Vitals are not established by the local development server.
